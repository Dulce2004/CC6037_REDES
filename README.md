## Descripción

Este repositorio contiene los entregables correspondientes al **Laboratorio No. 1: Esquemas de Comunicación e Introducción a Wireshark**.

Durante el laboratorio se realizaron actividades para comprender diferentes esquemas de comunicación, el funcionamiento de un conmutador y la utilización de **Wireshark** como herramienta para la captura y análisis de paquetes de red.
